Py2C Transpiler 🚀

A lightweight, high performance (kinda) desktop IDE and AST transpiler that converts Python code to C/C++ and runs them as an executable.

Download v1.1 (12 MB)

Features & Performance

  • 2 Tgs: Transpile Python to standard C (using bundled TinyCC) or C++ (via GCC/Clang).
  • Relatable Fast: ~0.919s for compiling and running C, ~2.881s for C++.
  • Built-in IDE: Dark-themed Tkinter editor featuring auto-indentation.
  • Zero Dependencies: No installation required, everything is bundled into the executable.
  • Supported Syntax: Variable assignments, math, loops (`range`), conditionals (`if/else`), `while` loops, lists, and user input.
