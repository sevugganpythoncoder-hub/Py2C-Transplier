py2c v1.1

A lightweight desktop IDE and AST transpiler that converts Python scripts to standard C/C++ and compiles them to standalone Windows executables.

Py2Cv1.1.zip
Windows only • 12 MB • Bundled with TinyCC
Download .zip

Performance & Architecture

  • Transpiles Python to C using TinyCC (~0.91s compile/run time).
  • Supports C++ targets via GCC / Clang (~2.88s).
  • Includes a dark-themed Tkinter editor with auto-indent.
  • No ext installation req everything is alr inside.

Supported AST Syntax

Handles basic variable assignments, math operations, range loops, if/else/elif conditional blocks, while loops, lists, and user input..,etc

# Input Python
x = 10
if x > 5:
    print("Valid")
