Performance & Architecture

  • Transpiles Python to C using TinyCC (~0.91s compile/run time).
  • Supports C++ targets via GCC / Clang (~2.88s).
  • Includes a dark-themed Tkinter editor with auto-indentation.
  • Zero external installation required—everything is self-contained.
